<h1 align="center">MovieChat</h1>

##  制作背景
ストリーミングサービスの普及により、視聴作品が分散してしまい、映画の感想を共有しづらいという課題があります。
「映画は共有することで魅力が倍増する」という考えのもと、映画好きが気軽に交流・発見できる場を作りたいと思い、本アプリを開発しました。

##  概要
**「異なる映画体験を、もっと自由に。」** <br>
MovieChatは映画好きが集まり、感想を語り合い、新しい映画を発見できるコミュニケーションプラットフォームです。

##  機能
| 機能 | 内容 |
|------|------|
| ログイン | ユーザー認証（Laravel Sanctum利用） |
| 映画検索 | TMDB APIを利用し映画を検索 |
| グループ管理 | 作成・検索・編集が可能 |
| チャット | Pusherによるリアルタイム通信 |
| 同時視聴 | 申請・承諾機能（再生は外部アプリ） |
| 投稿・コメント | レビュー投稿、コメント、いいね機能 |
| プロフィール | ユーザー情報の編集 |
| フォロー | ユーザー間のフォロー機能 |

## 特徴（こだわり）
- **高度な絞り込み検索**  
  グループ検索時に「ジャンル・年代・視聴プラットフォーム」で絞り込みが可能。自分に合うグループを迅速に発見できます。

- **快適な映画検索**  
  AJAXによるスムーズなページ遷移やページネーションを実装。直感的に映画を探せるUIを意識しました。  

- **リアルタイムチャット**  
  WebSocketを活用し、同時視聴中でもリアルタイムに感想を共有可能。  

- **同時視聴の申請・承諾**  
  申請・承諾システムで安全にグループを管理し、快適な同時視聴を実現。

## 楽しみ方
- **映画を語りたい人へ**  
  好きな映画の感想をシェアし、グループで語り合えます。  

- **誰かと一緒に観たい人へ**  
  同じ映画をリアルタイムで楽しみながらチャットで交流できます。  

- **新しい映画を探したい人へ**  
  グループや投稿から、自分では出会えなかった映画を発見できます。
